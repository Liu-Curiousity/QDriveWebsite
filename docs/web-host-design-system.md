# 网页上位机设计规范

本文件记录 Motor、Gimbal、Serial、CAN 以及后续新增网页上位机共用的界面规则。页面文件只负责业务内容和布局差异；可复用控件的视觉与状态必须定义在 `src/styles/web-host-controls.css`。

## 视觉角色

网页上位机只使用以下五类表面：页面、面板、控件、下沉信息区、浮层。颜色只承担中性、强调/TX、成功/RX、警告、危险五类语义。新增页面应优先复用现有 token 和组件类，避免在页面内重新定义近似样式。

## 视觉减法与层级

- 一级功能面板只使用 `--web-host-panel-outline` 的弱轮廓；不得用强描边、阴影或光效强化普通容器。
- 面板内的统计项、信号项和说明项属于下沉信息区，依靠共享背景差分组，保留透明占位边框以维持原有尺寸，不再重复绘制完整四边框。
- 日志、终端和数据表等连续工作区只保留上下结构边界，左右使用透明占位边框并取消圆角，避免在一级面板内形成第二个嵌套卡片。
- 未选中的分段标签使用透明边框，悬停、焦点和选中状态再提供必要反馈；不得让所有选项长期保持相同强度的轮廓。
- 状态点以实色圆点和状态文字共同传达语义，不使用外发光或装饰性光环。危险、警告、成功等语义不能只依赖颜色。
- 数据标签和统计数字原则上使用 500 或以下字重；除关键告警外，不使用 600–700 制造额外层级。
- 视觉减法本身不得删除字段、状态文字、键盘焦点或操作反馈，也不得改变页面网格、信息顺序和控件尺寸；左右密度调整仅允许移动后文规定的完整语义区块。

## 间距与功能分组

- 页面主栅格与同列一级卡片统一使用 `--web-host-layout-gap`（当前为 `1rem`），一级面板四边内距统一使用 `--web-host-panel-inset`（当前为 `1rem`）。Motor、Gimbal、Serial、CAN 的横向列间距、纵向卡片间距以及响应式换行后的行间距不得分别定义近似数值。
- 面板内独立任务段使用 `--web-host-section-gap`（当前为 `0.75rem`），同一任务段内的输入框、按钮和紧凑数据项使用 `--web-host-control-gap`（当前为 `0.5rem`）。新增页面不得引入 0.4、0.45、0.55、0.65rem 等近似间距补丁。
- 同一列中的连接、设备信息、参数和维护等任务保持独立卡片。卡片共用列基准线与间距 token，不使用贯穿整列的大外框将不同任务强行包裹。
- 独立卡片各自保留标题、ARIA 语义、背景和弱轮廓；卡片之间使用留白分组，不用额外分隔线模拟嵌套结构。
- 视觉分组不得合并表单、事件逻辑或状态管理，不改变字段顺序、控件 ID、页面主列结构和键盘操作路径。

## 边线、比例与数值对齐

- Motor / Gimbal 桌面布局采用“紧凑左栏、宽主工作区、标准右栏”的 `0.9 : 1.45 : 1` 比例，中间终端或波形区承担主要读取任务。响应式单列时所有一级板块统一占满可用宽度。
- 左右栏内每张独立卡片统一使用 `inline-size: 100%` 和 `box-sizing: border-box`，不得以内容宽度、固定宽度或额外单侧外边距破坏同列基准线。
- 连接区、设备操作区与参数操作区允许按钮按文字所需宽度分配空间，但整行始终贴齐卡片内容基准线，按钮文字保持水平与垂直居中。
- Motor / Gimbal 连接卡使用三条固定轨道：波特率整行、三个等宽连接操作、状态整行。波特率选择器、重启设备与下方查询组的最右按钮必须终止于同一右基准线。
- 同级且等权的维护操作使用三列等宽网格，首末按钮分别贴齐内容区左右基准线，不得使用内容宽度按钮造成单侧留白。
- 紧凑操作行的按钮间距与按钮横向内距统一使用 `--web-host-space-xs`，标签保持不换行，确保“读取参数 / 设置 / 储存 / 恢复默认”以及“读取设备信息 / 读取状态 / 清屏”在标准桌面侧栏中保持单行；该规则必须位于共享按钮尺寸规则之后，避免被通用内距覆盖。
- Motor 限幅参数使用两列等宽，通信参数使用 `1 : 1 : 2`，为较长的 `uart.baud_rate(bps)` 保留完整阅读宽度；Gimbal 的双轴输入保持两列等宽。
- 参数标签与输入框使用共享双行网格，标签轨道与输入轨道各自对齐，确保所有输入框顶边和底边位于同一水平基线。
- 紧凑参数栏中的工程字段名使用 `0.68rem` 等宽小字并保持单行，完整保留单位与键名；不得让 `timeout(s)` 或 `uart.baud_rate(bps)` 的孤立字符落到下一行。
- 数值输入框与纯数字选择器使用居中对齐及等宽数字。带下拉箭头的数字选择器必须预留左右等宽占位，使数字位于控件视觉中心，而不是仅在剩余空间中居中。
- 搜索框、终端输入、快捷指令和普通说明文本仍按阅读方向对齐，不得被数值居中规则影响。
- Gimbal 的驱动、自稳、激光状态使用三列水平状态轨道，每项必须同时显示对象名称与当前状态，禁止只并列三个无上下文的“未连接”或“状态未知”。控制模式、发送按钮与双轴数值输入使用固定网格轨道并共享左右边线。
- CAN 监视器顶部固定为“标题 / 筛选控件 / 工具按钮”三轨网格，所有可操作控件共享同一高度和水平中心线；窄屏时筛选轨道整体换到下一行，不允许单个控件随机折行。

## 分段标签

分段标签用于在同一区域切换并列内容，例如 Gimbal 的 Yaw / Pitch 参数面板。

- 容器使用 `.web-host-segmented-tabs`，并设置 `role="tablist"`。
- 每个选项使用 `.web-host-segmented-tab` 和 `role="tab"`。
- 选中状态以 `aria-selected="true"` 为语义来源；现有逻辑可同时保留 `.is-active`。
- 容器只负责网格、间距和排列，禁止在容器上添加底线、渐变背景、阴影或装饰性伪元素。
- 每个标签自行拥有完整边框和背景，不允许通过父容器或跨标签伪元素补画边界。
- 焦点状态必须使用统一强调色轮廓，不得移除键盘焦点提示。
- 页面专用 CSS 只能调整布局条件；不得重新定义分段标签的颜色、边框、圆角或活动态特效。

以上约束可避免父容器装饰与子控件边框叠加后产生残留白线、断线或跨主题颜色异常。

## 输入框内嵌下拉按钮

输入框内的下拉按钮使用 `.serial-dd--combobox` 与 `.serial-dd-trigger--embedded`。按钮默认透明、无边框、无阴影，输入框预留按钮空间。共享样式同时提供“可见输入框紧邻下拉按钮”的结构兜底，但新页面仍应使用显式类名。

## 下拉菜单与选项高光

- 所有上位机下拉浮层统一使用 `.serial-dd-menu`，选项统一使用 `.serial-dd-item`，页面不得自行复制下拉高光样式。
- 选项列表使用 `.serial-dd-menu[role='listbox']`，统一显示完整列表，不设置内部最大高度，不显示内部滚动条或预留滚动槽；页面滚动仍由页面本身承担。
- 选项保持 `width: 100%`、`margin: 0`，菜单统一使用 `0.4rem` 四边内边距。选项高光距浮层上、下、左、右四边必须一致，不得通过单侧 padding、负 margin 或定位进行补偿。
- 波特率等标准选项列表应控制在可直接扫描的数量内。若后续选项显著增加，应改用可搜索选择器，而不是重新加入狭窄的内部滚动条。
- `role='dialog'` 的发送设置等复合浮层不属于选项列表，可在内容确实超出可用高度时保留共享滚动规则。
- 新增上位机页面必须直接复用共享规则，不得在 Motor、Gimbal、Serial、CAN 的页面样式中分别修正高光宽度。

## 页面基准线

- Motor、Gimbal、Serial、CAN 及后续细分页统一使用 `.serial-tool-topbar` 作为顶部工具标题栏。
- 标题栏必须占满 `main.shell` 的内容宽度，并与下方主工具工作区共用左右基准线；不得套用正文阅读宽度或固定 `rem` 宽度。
- 左侧标题组合贴齐工具区左边线，右侧“返回工具列表”贴齐工具区右边线；响应式换行只能改变纵向排列，不得引入额外左右缩进。
- 对齐规则必须定义在共享样式中，页面不得用单独的 margin、padding 或定位数值修正返回入口。
- 设备信息、状态与清屏组成的操作组使用 `.serial-side-block--device-summary`；外框必须与同侧相邻面板共用左右基准线。按钮按文字所需宽度弹性扩展并占满内容区，使外框四边内距一致，不得通过收窄面板破坏纵向对齐。
- 快捷发送等紧凑操作列表必须与标题栏共用左右内容基准线。列表和每一行均占满内容宽度；需要滚动时保留滚轮与触摸滚动能力，但隐藏内部滚动条并使用 `scrollbar-gutter: auto`，不得为不存在的滚动条长期预留单侧空槽。

## 按钮内容对齐

- 上位机操作按钮统一使用 `inline-flex`，并通过 `align-items: center`、`justify-content: center` 和 `text-align: center` 保证文字及“图标 + 文字”组合在按钮内水平、垂直居中。
- 按钮因栅格或弹性布局变宽时，内容仍须保持视觉中心，不得继承左对齐或用额外 padding 人工补偿。
- 面板内需要横向填满的并列操作使用 `.serial-btn-row--fill`。按钮按文字所需宽度弹性分配剩余空间，按钮组左右边线与面板内容区对齐；窄屏空间不足时允许整枚按钮换行，不截断文字。
- 纯图标按钮遵循同一居中规则。普通下拉触发器保留标签靠左、箭头靠右的布局；纯数字选择器按“左右等宽占位 + 数字居中”处理。
- 居中规则必须定义在 `web-host-controls.css` 共享按钮层，页面专用样式不得为同类按钮重复或覆盖对齐方式。
- 通用按钮选择器中的历史 ID 必须使用 `:where()` 消除额外特异性，避免通用 padding 等规则压过分裂按钮、图标按钮的局部尺寸约束。

## 分裂按钮边界

- 主操作与下拉触发器组合成分裂按钮时，外层容器只负责统一圆角与裁切，不得绘制额外外轮廓；两个子按钮必须使用 `border: 0`、`border-radius: 0` 和 `box-shadow: none`，以一块连续填色呈现组合关系。
- 两个子按钮的连接处必须保持直角，不得使用内侧圆角。内部竖分隔线由外层容器的独立伪元素绘制，统一使用 `--web-host-split-divider-width` 宽度 token（当前为 1px）和所在面板的背景色 token；分隔线不得绘制在任一子按钮上，避免被子按钮的禁用透明度一并弱化。
- 下拉箭头使用 `--web-host-split-chevron-size` 尺寸 token（当前为 `1.15rem`），箭头触发区必须清除通用按钮的横向内边距，避免图标被 Flex 压缩，并在固定宽度内水平、垂直居中；不得用单侧位移补偿。展开状态只允许围绕自身中心旋转。
- 不得让两个子按钮各自绘制完整轮廓，否则接缝上下会出现双重亮边或残留圆角。
- 外层不得使用白色、文字色或高对比色边框包围整个组合控件；外形应由按钮自身填色与裁切边界自然形成。
- 键盘焦点在子按钮内部使用内描边显示，不能因外层裁切而丢失焦点提示。

## 连续数据区域背景

- 波形 Canvas 默认保持透明，直接继承承载面板的背景；绘图代码只绘制网格、数据、坐标与交互提示。
- 禁止在 Canvas 绘图脚本中用页面专属十六进制颜色填充整块画布，否则会在浅色或深色主题下形成无语义色块。
- 终端、日志和数据表确需形成独立连续表面时，必须使用共享 surface token，不得硬编码页面专属背景色。
- 新增页面须同时检查浅色与深色主题，确保同一层级的连续工作区背景一致；图表线条、控件和浮层仍按各自语义保持必要对比度。

## 维护要求

- 新增共享模式时，先在 `web-host-controls.css` 中定义语义类，再在页面中使用。
- 一个组件最多保留五种视觉变体；更多变体应拆分为新的功能模式。
- 页面交付前检查默认、悬停、焦点、活动、禁用状态，以及浅色/深色主题。
- 每次修复可复现的层叠问题，都应在 `tests/web-host-ui.test.ts` 增加回归约束。
