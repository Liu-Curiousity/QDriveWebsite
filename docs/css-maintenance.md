# CSS 维护

## 修改现有外观

先在浏览器中确认实际生效的声明，再修改定义它的规则。替换旧设计时同时删除被取代的声明，不另加一套高权重选择器或 `!important`。一个元素同时匹配基础规则、真实变体和交互状态是正常的；同一个属性经历多次无意义覆盖需要清理。

公共声明可以放在分组选择器中，组件独有属性留在自己的规则里。保留可读格式；移动文件、压缩成一行和删除注释不算完成精简。

## 文件职责

- `site-shared.css`：全站基础、共享组件、导航和页脚，以及跨页面共用的排版声明。
- `product-detail.css`：产品/方案首屏、卖点、图库、规格和下载入口，仅由 QD4310、QGimbal、QCar 页面引入。
- `resource-download.css`：产品/方案的资源与固件下载弹窗，仅由 QD4310、QGimbal 页面引入；通用弹窗基础仍在 `site-shared.css`。
- `auth-control.css`、`account-page.css`：登录、账户组件与账户页面。
- `web-host-controls.css`：上位机共享控件与按钮；`gimbal-tool.css` 负责 Gimbal 专用布局和轴切换，`serial-assistant.css` 负责 Serial 发送区及 Serial / CAN 共用布局。
- 商城、管理后台、活动等专用文件：维护对应组件，不追加全站覆盖。
- 悬停提示继续复用 `assistant-tooltip.css` 和 `data-tooltip`，见 `ui-tooltips.md`。

## 验证

运行 `npm run check:styles`、`npm run check` 和 `npm run build`。样式检查会识别独立选择器与分组选择器之间的重复声明。涉及跨规则精简时，比较浏览器中的实际布局与计算样式，包含窄屏、深浅主题、焦点、悬停、禁用以及弹窗展开状态。

CSS 的测试不能要求固定注释、分组顺序或空白排版。`tests/css-source.ts` 为声明测试提供按选择器汇总的视图，并保持媒体查询和层的作用域；它不代替浏览器级联验证。

## 全站共享样式的专项清理

以下基准为本轮修改前的 `site-shared.css`；清理后将两个新增文件一起统计，代码迁移不计作净删除。源码字节统一按 LF 换行计算，排除 CRLF 差异。

| 指标 | 清理前 | 清理后（三文件合计） |
| --- | ---: | ---: |
| CSS 声明 | 1,518 | 1,448 |
| 选择器规则块 | 395 | 378 |
| 源码字节 | 61,554 | 58,063 |
| 行数（含文件末尾换行） | 2,956 | 2,841 |

净减少 70 条声明、17 个规则块，源码体积减少约 5.7%。`site-shared.css` 自身为 1,801 行；该文件的降幅同时包含专用样式迁移，不能全部算作精简。

- 下载入口保留当前 Grid 列表，删除旧 Flex 卡片布局、尺寸和重复外观声明。
- 卖点容器保留 Flex 布局，删除无效 Grid 属性和被覆盖的英文高度。响应式宽度保留前两张与后续卡片的实际差异，不再通过重复枚举全部 `nth-child` 叠加权重。
- 永久隐藏的首屏、页脚装饰伪元素只保留隐藏规则；删除没有引用的导航文字阴影变量。
- 合并相同章节间距；删除弹窗列表、悬停和窄屏中重复的声明。相邻状态在原规则内嵌套，且每个分组分支都必须属于同一个基础选择器。
- 产品/方案专用规则按页面加载；混合使用的全站排版和通用弹窗仍保留在共享文件，避免重新复制。

验证采用同一页面 DOM 切换本轮修改前后的样式：全站 228 组对照覆盖 19 个页面、深浅主题、桌面和窄屏，以及悬停、焦点和展开的弹窗；产品页另外完成 96 组对照，复查英文、1440 / 800 / 700 / 390px 宽度、元素实际位置和尺寸、移动导航展开和禁用按钮。唯一保留的计算属性差异是 Block 下载列表上已删除的无效 `gap`，它不参与当前布局。样式检查、类型检查和生产构建通过。未连接真实硬件；管理页面按当前未登录状态验证。

资源弹窗测试改为检查当前面板声明和页面引入关系，不再依赖已经不存在的注释或旧版外观。测试基线为 42 项通过、11 项失败；本轮为 43 项通过、10 项原有失败，没有新增失败。

## 产品与兑换按钮

产品页“立即购买”、固件弹窗“下载固件”、优惠券弹窗“提交兑换申请”直接使用 `.btn-primary`；“资料下载”和兑换弹窗“取消”使用 `.pill-action`。公共尺寸、500 字重、正文级字号、行高、焦点和禁用状态统一在 `site-shared.css` 中定义，主次变体只负责颜色和交互差异。产品首屏不再单独覆盖次按钮尺寸，固件下载不再使用 `resource-download-action`。

账户弹窗操作栏使用 `.account-dialog-actions`，只负责排列、间距和窄屏换行。裁剪、贡献审核、兑换、删除确认及复用贡献弹窗的活动申请按钮直接使用公共主次类，不再依赖 `account-crop-dialog__apply` 等旧按钮类。登录提交、弹窗内验证码、资料保存和邮箱操作同样复用公共按钮。账户页的广泛字号规则排除公共按钮，避免用 `!important` 覆盖它们。

个人主页内的“发送验证码”“验证当前邮箱”、安全设置和积分操作保留透明背景与下划线外观，由 `account-page.css` 自己维护；其安全操作类为 `.account-security-action`。这些页内操作不能因为弹窗样式整合而改成填色按钮。页眉菜单切换、关闭图标、文字链接和文件条目的小型移除控件仍保留对应组件样式。

验证：五种按钮在两产品页和账户页、深浅主题、1440 / 390px 下完成 128 次正常、悬停、焦点、按下状态比较，同类按钮计算样式一致；禁用按钮不可交互且无按下位移。兑换操作栏另检查中文、英文的 390 / 320px 布局。四个上位机完成 64 组前后对照，无计算样式或位置尺寸差异。

账户弹窗后续清理以该轮开始时的工作区为基准，合计统计 `auth-control.css` 与 `account-page.css`：声明从 1,724 减至 1,577，规则块从 508 减至 473，行数从 3,572 减至 3,278。净删除 147 条声明、35 个规则块、294 行；统一 LF 后源码从 79,021 字节减至 71,944 字节，减少约 9%。计数包含为保持个人主页原样式而保留的全部声明。

后续验证：个人主页按钮与输入框完成深浅主题、1440 / 390px 及五种交互状态的 20 组前后对照，无差异；可见账户弹窗公共按钮完成 264 次状态比较；六种弹窗完成中英文、1440 / 390 / 320px 的 36 组布局检查。样式检查、类型检查、生产构建通过；测试 43 项通过、10 项原有失败。

## 上位机字重

Motor、Gimbal、Serial、CAN 共用两档字重：正文、字段标签和辅助说明为 400；标题、按钮、输入框（含多行文本）、下拉当前值及选项、强调信息为 600。共享字重规则位于 `src/styles/web-host-controls.css`，组件中已被合并的声明不要重新添加。字段容器不再以加粗整个容器的方式强调标签；输入与下拉控件共用 600 字重，选项明确使用 600，避免继承外层标签的字重。弹窗标题及 `strong`、`b` 同样遵循 600。全站导航和页脚沿用网站自身规范。
